# Operating System Practical - 01: Basic Linux Commands

## 📋 Executed Commands Overview

Below is the structured summary of the 15 basic Linux commands executed during the practical session:

| # | Command | Purpose / Description | Output / Example Usage |
|---|---|---|---|
| 1 | `pwd` | Print working directory | Displays absolute path (e.g., `/home/ubuntu/Desktop`) |
| 2 | `whoami` | Print active username | Outputs current user (`ubuntu`) |
| 3 | `uname` | Print system kernel details | Displays OS kernel name (`Linux`) |
| 4 | `mkdir test_folder` | Create a new directory | Creates directory `test_folder` |
| 5 | `ls` | List directory contents | Displays files and folders in current directory |
| 6 | `cd test_folder/` | Change directory | Navigates into `test_folder/` |
| 7 | `touch file1.txt` | Create an empty file | Creates empty file `file1.txt` |
| 8 | `echo "Hello Linux" > file1.txt` | Write text into a file | Redirects string `"Hello Linux"` into `file1.txt` |
| 9 | `cat file1.txt` | Display file contents | Prints contents of `file1.txt` (`Hello Linux`) |
| 10 | `cp file1.txt file2.txt` | Copy file contents to new file | Creates duplicate `file2.txt` |
| 11 | `wc file1.txt` | Word, line, and byte count | Displays counts for `file1.txt` (e.g., `1 2 12 file1.txt`) |
| 12 | `df` | Report file system disk space usage | Displays mounted filesystems and space details |
| 13 | `ps` | Display current active processes | Lists active shell processes (`bash`, `ps`) |
| 14 | `grep "Hello" file1.txt` | Search text patterns in file | Matches and outputs lines containing `"Hello"` |
| 15 | `clear` | Clear terminal screen | Clears visible terminal buffer |
